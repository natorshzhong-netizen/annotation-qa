# 客服工单意图分类 · 标注规范 v1.2

## 一、任务
给每条客服工单打**一个**意图标签，共 8 类。

## 二、类别定义

| 标签 | 定义 | 正例 |
|---|---|---|
| 退款退货 | 用户要求退还货款或退回商品 | 想退掉、退款没到账 |
| 物流查询 | 询问或反馈物流、配送、收发件状态 | 快递没动、查单号、改地址 |
| 商品咨询 | 询问商品本身属性、规格、库存、售后政策 | 电压、续航、保修多久 |
| 账号问题 | 登录、注册、密码、账号状态异常 | 登不上、被冻结、验证码收不到 |
| 发票报销 | 开具、下载、修改发票相关 | 开发票、专票、电子发票 |
| 投诉建议 | 对服务、人员、平台表达不满或建议 | 投诉、举报、态度差 |
| 优惠券活动 | 优惠券、满减、活动、会员权益、积分 | 券用不了、活动还有吗 |
| 其他 | 以上都不属于 | — |

## 三、判定优先级
一条工单涉及多个意图时，按以下顺序取**第一个命中**的：
1. 投诉建议
2. 账号问题
3. 退款退货
4. 发票报销
5. 优惠券活动
6. 物流查询
7. 商品咨询

## 四、通用规则
- 只打一个标签，不允许空标。
- 文本信息不足时，按字面最接近的类别标。
- 拿不准的按优先级规则走，不要自创新类。
